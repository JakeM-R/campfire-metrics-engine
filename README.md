# Month-end metrics pack, built for Campfire

One page, no accounts. Drop in an ARR-by-customer-by-month export, a CRM deals export and a vendor list. It builds the ARR bridge, NRR/GRR, bookings and pipeline coverage, runs a commission calc for the last closed quarter, lists vendor renewals by notice deadline, and flags every place the CRM and the revenue schedule disagree.

Runs entirely in the browser; files are never uploaded. Ships with a fictional demo company generated from a fixed seed, including five planted CRM-vs-schedule exceptions.

Built by Jake Makking-Robinson.
